# AI Git — Netflix-inspired presentation website

Open `index.html` in a browser.

## Replace these placeholders
- Architecture: edit the `architecture` episode in `script.js`.
- Code: edit the `code` episode in `script.js`.
- Progress: edit the `progress` episode with your real milestones.
- Memes: replace the three meme cards in `index.html` with your images if desired.
- Intro sound: add your own audio as `assets/intro.mp3`; do not use copyrighted Netflix audio unless you have permission.

## Presentation controls
- Click Presentation.
- `ESC` exits presentation mode.
- `→` moves to the next episode while an episode is open.
- Click outside an episode to close it.
